**Pebble 0.3.0** is a pre-release. It adds a calendar, encrypted backup, history and restore, search by meaning, and a brain that learns from you at once. Your data stays on your laptop. Please report problems with *About → Report a bug* or *Pebble misunderstood me*.

## Install
1. Download **`Pebble-0.3.0.msi`** below. The models are inside. **`Pebble-lite-0.3.0.msi`** is smaller and has no voice; you can add voice later as a signed model pack (About → Model packs).
2. Optional: in PowerShell, run `Get-FileHash .\Pebble-0.3.0.msi` and compare the hash with `SHA256SUMS`.
3. Run it. It installs only for you; you do not need admin rights. If Windows shows *"Windows protected your PC"*, click **More info → Run anyway** (the installer is not code-signed yet).
4. An update from 0.1.2 keeps your data. Pebble upgrades the database at the first start. **Tip:** make a backup first (About → Backup) after the update, and keep the passphrase safe.

Requirements: Windows 10/11 x64, about 1 GB of disk space, 8 GB RAM recommended, a microphone for voice.

## New
- **Calendar:** events; daily, weekly, monthly and yearly repeats; ICS import and export (Google, Outlook); an agenda on the Today page; reminders before events. Quick Add: `event: dentist friday 5pm for 30 min`.
- **Encrypted backup and restore** (About → Backup): one file, AES-256-GCM, a key from your passphrase. A restore on a new PC keeps that PC's identity.
- **History and restore:** old versions of notes, reminders and events stay for 90 days on this PC. Restore a version, bring back a deleted item ("Recently deleted" on the Memory page), or delete the old versions of one item.
- **Edit a note** on the Notes page.
- **Search by meaning:** find notes, facts and what you said in your own words. New command model **v3** with a sentence embedding.
- **Pebble learns you at once:** what you teach, and what you pick in "Did you mean…?", changes the next similar sentence without a retrain.
- **Smart replies (optional, off by default):** small talk from a local chat model on `127.0.0.1` only. English only. It needs the signed chat pack.
- **Signed model packs** and a **lite installer**.

## Faster and steadier
- Events are written off the UI thread, in batches. All-time stats are about 5 times faster on long histories. The model check at start went from about 180 ms to about 1 ms.
- Every database transaction begins `IMMEDIATE`, so "database is busy" errors are gone.

## Fixed (QA round 1)
- A restore that failed half-way could leave an empty database. Now each step is undone on failure, and a crash during a restore is repaired at the next start.
- One failed disk write stopped the event log. Now the writer retries and reports to `pebble.log`.
- Some monthly repeats froze the app at start. Events imported in another time zone showed on two days. A VEVENT without END lost the later events.
- With the pet hidden, no reminder appeared. Now a due reminder becomes a Windows notification.
- A second launch from the Start menu did nothing while Pebble ran. Now it opens the window.
- ONNX Runtime and sherpa-onnx left a new DLL folder in `%TEMP%` at each start (GBs over time). Now the DLLs ship in the app, and Pebble removes the old folders.
- A voice clip from a closed Quick Add could run later. A fast Enter could run the result for the previous text.
- Huge numbers in a command crashed the parser.
- Smart replies froze the window for 1–6 s; a quit during start-up left the chat server running; the chat port was briefly open to other apps.

## Privacy
No account, no cloud, no analytics. Sync is prepared in the data, but Pebble opens no network connection to other devices yet. See [PRIVACY.md](https://github.com/Wickedsoni/pebble/blob/main/PRIVACY.md).
